01
сессия · сервер и мозг
15 минут

Задача: подключить мозг Гермесу на своём сервере.

Hostinger: hPanel, ваш VPS, Docker Manager, терминал контейнера Hermes. Свой сервер: ssh. Ссылку входа в Portal откройте на ноутбуке.

hermes config set timezone Europe/Nicosia hermes setup --portal

Свой ключ: hermes setup. Гермеса на сервере ещё нет: curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash, затем source ~/.bashrc. Managed Hermes: всё в мастере hPanel, сразу к шагу 03.

Сервер живёт по UTC: без первой строки задача на 17:00 приходила у нас в 20:00.

Готово, когда: набираете hermes, пишете «привет» и он отвечает.

01+
запасной путь · нет сервера или он не пускает
не тратьте больше 5 минут

Сегодня ставим на ноутбук, переезд на сервер дома. Mac: откройте Терминал и вставляйте по одной строке.

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash source ~/.zshrc hermes setup --portal

Windows: PowerShell, команда iex (irm https://hermes-agent.nousresearch.com/install.ps1), затем hermes setup --portal. Помните: закрыли крышку, Гермес уснул. Это временно, до переезда.

Готово, когда: набираете hermes, пишете «привет» и он отвечает.

!
если установка упала
не тратьте больше 5 минут

Ошибка в терминале? Не ищите её в интернете. Отдайте Claude Code, он у вас уже стоит.

Установи мне Hermes Agent от Nous Research на этот компьютер по официальной инструкции hermes-agent.nousresearch.com/docs. Если упадёт ошибка, разберись в причине и почини сам, по шагам объясняя, что делаешь. Мои токены и ключи не печатай и не проси вставлять в чат: где нужен ключ, остановись и скажи, какую команду я запускаю сам. В конце проверь командой hermes doctor, что всё работает.

Упало на сервере? Скопируйте текст ошибки без токенов и дайте Claude Code с вопросом «что это и какую команду мне запустить».

Готово, когда: hermes doctor не показывает красных пунктов.

02
сессия · Telegram
10 минут

Задача: поселить Гермеса в вашего бота.

Мастер спросит платформу (выбирайте Telegram), токен бота и ваш ID.

hermes gateway setup

Потом перезапустите шлюз, иначе бот не увидит настройки. Hostinger: кнопка Restart у контейнера в Docker Manager. Свой сервер: hermes gateway install и hermes gateway start, тогда бот переживёт закрытие ssh. Ноутбук: hermes gateway.

Откройте бота в Telegram и отправьте /sethome: сюда будут приходить рутины. Затем: «Привет! Кто ты и что умеешь?»

Готово, когда: бот ответил в Telegram.

03
сессия · голос
10 минут

Задача: чтобы Гермес понимал вас по-русски и отвечал голосом.

hermes config set stt.language ru hermes config set stt.local.model small hermes config set tts.provider elevenlabs

Ключ ElevenLabs наберите сами: hermes config set ELEVENLABS_API_KEY ваш_ключ. Он ляжет в файл настроек, а не в чат. Перезапустите шлюз, как на шаге 02. В Telegram отправьте голосовое, затем /voice, чтобы Гермес отвечал голосом.

По умолчанию Гермес ждёт английскую речь и берёт самую лёгкую модель распознавания. Без этих строк русские голосовые превращаются в кашу, у нас так и было.

Готово, когда: Гермес показал текст вашего голосового без ошибок и ответил голосом.

04
сессия · знакомство
10 минут

Задача: чтобы Гермес знал вас, а не мир вообще. Пишем ему в Telegram.

Ниже текст обо мне. Сохрани его в мой профиль пользователя в памяти, уложи в лимит профиля без потери смысла. Из части «как со мной говорить и что делать нельзя» предложи правила для своего характера в SOUL.md: сначала покажи, запиши только после моего «да». В конце перескажи в трёх строках, кто я и чем занимаюсь, чтобы я проверил. [вставьте свой текст о себе]

Профиль уходит в каждый запрос, поэтому туда только выжимка, остальное живёт в базе (шаг 05). Не влезает: hermes config set memory.user_char_limit 4000.

Готово, когда: пересказ точный. Проверка: отправьте /new и спросите «над чем я сейчас работаю?» Новый диалог, а он помнит.

05
сессия · ваша база из GitHub
10 минут

Задача: Гермес знает не только профиль, а всю вашу рабочую папку из Claude Code. Пишем ему в Telegram.

Подключи мою рабочую папку из GitHub: [ссылка на приватный репозиторий]. Создай отдельный SSH-ключ только для чтения, покажи его публичную часть и скажи, куда в GitHub её вставить, жди моего «готово». Затем склонируй репозиторий в папку workspace в своём домашнем каталоге и сделай её своей рабочей папкой (terminal.cwd). Подтягивай обновления раз в час скриптом, без модели. В саму папку ничего не пиши, свои файлы клади рядом. Если там есть CLAUDE.md, а AGENTS.md нет, предложи сделать AGENTS.md из CLAUDE.md. В конце назови три моих текущих проекта и файлы, где они описаны.

Гермес читает AGENTS.md, а не CLAUDE.md, и без terminal.cwd не видит папку: у нас он называл старую цель. Перед заливкой проверьте папку на ключи: у нас нашлось 10 файлов с секретами.

Готово, когда: Гермес назвал ваши проекты со ссылками на файлы. Нет GitHub? Это домашка.

06
сессия · первая рутина
15 минут

Задача: отдать Гермесу первую повторяющуюся задачу из вашей тройки.

Хочу отдать тебе повторяющуюся задачу: [задача, например «план дня по моим проектам»]. Делай её [когда, например «каждый будний день в 8:00»] по кипрскому времени, результат присылай сюда, в этот чат. Формат: первая строка - вывод одной фразой, дальше не больше трёх действий «что - кому - до когда», всего до 800 знаков, без пересказов. Если сказать нечего, не присылай ничего. Сначала коротко покажи, как ты понял задачу и расписание. После моего «да» заведи задачу по расписанию и сразу сделай один пробный запуск, чтобы я увидел результат.

Без лимита Гермес пишет простыни: у нас было 15 сообщений и 22 700 знаков в день. Теперь 3 коротких обзора.

Готово, когда: пришёл пробный результат, а /cron list показывает следующий запуск по кипрскому времени (+03:00), а не по UTC.

07
сессия · ключевые сервисы
кто успеет · остальные дома

Задача: дать Гермесу руки. Почта и календарь Google, Гермес ведёт сам.

Подключи мои почту и календарь Google через свой навык Google Workspace. Веди меня по шагам, по одному за раз, и жди моего «готово». Ключи и секреты не проси вставлять в чат. Когда подключишь, покажи: что у меня в календаре на завтра и какие письма за сутки ждут моего ответа. Ничего не отправляй и не меняй.

В Google Cloud на экране согласия OAuth нажмите Publish app (рабочий домен Google Workspace: тип Internal). В режиме Testing Google отзывает доступ через 7 дней: так 27.09 почта отвалилась сразу у двух наших Гермесов. Экран «Google hasn't verified this app» для своего приложения нормален.

Не Google? В терминале hermes mcp: каталог готовых подключений. Готово, когда: Гермес показал ваши реальные встречи и письма.

четыре правила безопасности

У Гермеса ключи от вашего сервера

01

Токены не пересылать

Ни в общий чат, ни нам. Утёк токен бота: сразу /revoke в @BotFather.

02

Только вы

Бот слушает только ваш Telegram ID. Чужие сообщения он игнорирует, не расширяйте список без нужды.

03

Наружу только после «да»

Письма, сообщения людям, платежи: сначала показать, потом сделать. Впишите это в его правила.

04

Бот = пульт от сервера

Через Telegram Гермес выполняет команды на сервере. Не держите там чужие проекты и не выключайте подтверждения опасных команд (/yolo).
