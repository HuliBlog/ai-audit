Техническая архитектура

Mg Intelligence Home общается с вашей системой через интеграционный слой, а не заменяет панель управления.

  1. 1Голос или чат резидента
  2. 2ИИ-слой Mg Intelligence Home: личность, память, логика
  3. 3Интеграционный слой: API и драйверы
  4. 4Ваша система: KNX / Control4 / Crestron
  5. 5Свет, климат, шторы, ворота, медиа

Мы читаем и отправляем команды через ваш существующий API или драйвер. Мы не заменяем панель управления и не переписываем вашу конфигурацию.
